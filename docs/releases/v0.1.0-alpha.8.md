GoTavern is a standalone Go reimplementation of the SillyTavern 1.19.0 server/backend. It runs the
unmodified upstream frontend over the same routes, the same `config.yaml` semantics and the same on-disk
data layout, so an existing SillyTavern directory works without a conversion step.

**This is an ALPHA.** Not yet a daily driver for a data directory you cannot restore. Keep a backup before
migrating, and read *Known boundaries* below before you do.

Alpha 8 closes **the one explicit proof gap Alpha 7 left**, and changes nothing a user clicks. The gap was the
streaming abort judge: whether a connection that dies mid-stream behaves identically on GoTavern and on pinned
Node, judged through a real TCP hop rather than an in-process stub. Closing it took seven changes, each
removing a named, measured defect, and **no runtime Go file changed.**

rests on a run whose tree is identical to what merged:

- `Browser differential` run **40682654579** -- **success**. Steps 15 (record), 16 (compare) and 17
  (gate-has-teeth) all passed, with both abort legs byte-identical:
  `mode "cut"`, `cut "cut-after-bytes"`, `cutsPerformed 1`, `releasedBytes 349`,
  `plaintextOffsetAtCut 513`, `contentStates 2`, `textAfterCut "Hello from the"`.
- `git diff c3ed9f5 a319cd4` is **identical**, so that green judges the merge rather than a commit near it.
- The comparator's 28-case selftest and the verifier's 14-case selftest both ran **in CI** and passed: every

**The oracle is green for a legitimate reason.** `GoTavern CI` **40753808420** -- success across `changes`,
`browser-evidence`, `verify` and `oracle`, with the pinned rebuild (step 12) and the committed-results check
(step 19) both passing.

## The seven defects fixed

Each of these produced a red run, and each is recorded because the reasoning outlives the fix.

1. **The recorder returned nothing.** The abort drive's render recorder reported the length of a list that did
   not exist, so every abort leg timed out carrying no observations at all. Measured `renderStates`
   **0 -> 2 (GoTavern) / 1 (pinned) -> 4**.
2. **The cut point made its own guards unsatisfiable.** The abort leg cut at the *head* of the body, which
   releases no content frame, so the three partial-text guards could never be true
   (`contentStates: 0`, `textAfterCut: null`). The leg now cuts after three complete frames -- 513 of 2,565
   bytes -- and both subjects render identical partial text: `contentStates: 2`,
   `textAfterCut: "Hello from the"`.
3. **The comparison artefact was claimed by nobody.** `streaming-framing-comparison.json` had no row in
   `tests/browser/sources.mjs`, so by the harness's own rule it read as *nothing* rather than as a pass. The
   verifier's invariants now run against it.
4. **The guard set contradicted itself.** `releasedBytesUnderCut === 0` beside `contentStates === 2` cannot
   both hold -- the guards described a vehicle that no longer existed. Re-derived for the cut-after-frames
   surface, with two guards **renamed to what is actually measured**: `peerDidNotDisconnect` ->
   `peerSawTheClientDisconnect`, and `pageReturnedToIdleOnBothSubjects` ->
   `bothSubjectsLeftGeneratingWithTheStopButtonUp`.
5. **The timeout path discarded its own observations.** It returned an error string and no `postSend`, so four
   guards compared two empty arrays -- equal, but vacuously. They now read populated data.
6. **Two verification rules recorded** (`AGENTS.md` 102 and 103), each with the measurement that produced it:
   a guard must read the fact its name claims *and may live in more than one file*; and a run must not be
   spent before comparing the fields a producer writes against the fields a consumer reads.
7. **The oracle's shape declarations were documentation, not constraints.** One probe, three layers: the
   stability checker compared a field the probe declares `rule: 'null'` (a wall-clock mtime); the writer
   declared that field uncomparable and wrote the real value anyway, so the committed fixture could never
   re-record deterministically; and the fixture therefore carried a value its own schema forbids. All three
   are fixed, and the writer now **enforces** its declaration rather than describing it. The exclusion was
   proven not to be a suppression: fields the probe does *not* declare still fail the comparison, by name.

## Known differences

**One recorded difference, outside this release's committed scope.**

`Browser differential`'s `helper variables (narrow)` surface reports
`asymmetries=[survivesRestart] (gotavern=true, pinned=false)` with **`mismatches=[]`** -- no request or
response content mismatch at all. After a server restart in a new process, GoTavern still holds a 酒馆助手
variable value where pinned loses it. It does *more*, not less, and it is still a difference a user migrating
from pinned could notice. Measured identically on runs **40681692737** (`24babdc`, before the merge) and
**40689195294** (`a319cd4`).

**Open, recorded rather than implied:** the same artefact declares `survivesRestart` and `offIsTheControl` as
**required for its claim** while listing them as **unproven** -- it contradicts itself about its own coverage --
and its claim is blocked by `guards.globalScopeReachesWire is false`. That surface is therefore **not claimed
as proven** here, and both the judge inconsistency and the product question are carried to their own lane,
evidence first.

## Known boundaries

**What will not work, stated before you migrate.**

Accepted exclusions -- deliberate decisions, not gaps:

- **Arbitrary Node.js server plugins.** Not emulated and not faked; a route that depends on one reports that
  boundary rather than pretending.
- **Local in-process ML.** Captioning, classification and speech through SillyTavern's built-in local models
  require an ONNX runtime inside the server, which contradicts the `CGO_ENABLED=0` distribution rule. These
  routes report `not implemented` with that reason.
- **Image re-encoding through a Jimp-compatible codec.** `/api/avatars/upload` and `/thumbnail/<computed>` are
  the output of Jimp; a Go implementation cannot reproduce those exact bytes without adopting a codec, so
  neither is claimed through HTTP comparison alone.
- **Behaviours whose wire format lives inside a dependency** rather than in the pinned server's source --
  Google's `batchexecute` voice path and `/api/translate/{google,bing}`.

Work not yet started, and not claimed:

- **continue (P2)** -- not started.
- **hand-back to Node (P3)** -- not started.
- **backgrounds (P4)** -- not started.
- **酒馆助手 variables after restart** -- the two open items above.
