## Rules this log follows

1. A row's `status` is `DONE` only with the cited command/run and its real output in the repository.
2. `BLOCKED` rows name the exact requirement that failed and the run id that showed it.
3. A decision that is "safer but different" from pinned is recorded as a **deliberate divergence** with its
   scope words; it is never absorbed silently into a `compatible` claim.
4. No row is edited to make an earlier row look better: a superseded row keeps its history and a later row
   says what replaced it.
